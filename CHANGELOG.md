# Changelog

## 1.0.0

First release.

- Explorer context-menu item with a dialog for building and running robocopy copies.
- Live command preview, dry run, and exact quoting verified against real robocopy.
- Built-in and custom presets, recent destinations.
- Safety checks for self-copies, risky mirrors, and deleting options.
- Progress, cancel, plain-language results, logs, and retry failed.
- Elevation through UAC with mapped drives converted to UNC.
- Per-user double-click installer and uninstaller (no admin rights).
